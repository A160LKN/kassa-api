**Коротко:** 92 автотеста и смоук всего сценария покупки на собранном Docker-образе. Главный упор — на то, что стоит денег: 50 одновременных покупателей на одно место, 10 повторов с одним Idempotency-Key, 5 одновременных вебхуков, поздняя оплата с возвратом. 19 из 20 функций покрыты автотестами полностью.
